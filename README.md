# AutoReaction

ربات ری‌اکشن خودکار برای کانال و گروه تلگرام — نسخه‌ی عمومی (چندکاربره).

## امکانات
- هر کاربر چت‌های خودش را ثبت می‌کند (با اضافه‌کردن ربات به‌عنوان ادمین، خودکار ثبت می‌شود)
- **ربات خود کاربر**: توکن خودش را می‌دهد (رمزنگاری‌شده ذخیره می‌شود، پیام بلافاصله پاک می‌شود)
- **سرویس ما**: توکن‌هایی که ادمین ثبت کرده؛ دسترسی با `/grant` یا باز بودن برای همه
- **ری‌اکشن رندوم** یا **لیست ایموجی خود کاربر**
- تنظیم هر چت: روشن/خاموش، احتمال، تعداد ربات سرویس، منبع ربات‌ها
- **ادمین‌کردن خودکار ربات‌ها** توسط ربات اصلی (دکمه‌ی 🛡 یا خودکار هنگام ثبت چت)
- توکن باطل‌شده خودکار غیرفعال و به صاحبش اطلاع داده می‌شود
- پنل مدیریت: آمار، ربات‌های سرویس، کاربران، `/ban` `/grant` `/revoke`
- اگر `state.json` نسخه‌ی قبل کنارش باشد، یک‌بار خودکار وارد می‌شود

## راه‌اندازی
```bash
cp .env.example .env   # MAIN_BOT_TOKEN و OWNER_IDS را پر کن
pip install -r requirements.txt
python main.py
```
روی Railway: یک **Volume** وصل کن و `DATA_DIR=/data` بگذار، وگرنه با هر دیپلوی دیتابیس پاک می‌شود.
`SECRET_KEY` را حتماً ست و نگه‌داری کن (بدون آن توکن‌های ذخیره‌شده خوانده نمی‌شوند).

## نکته‌های تلگرام
- ربات اصلی باید ادمین چت باشد و دسترسی «Add New Admins» داشته باشد تا بتواند بقیه را ادمین کند.
- تلگرام حداکثر ۵۰ ادمین در هر چت اجازه می‌دهد؛ سقف ربات سرویس برای هر چت ۴۰ است.
- در گروه‌ها ربات‌ها باید قبلاً عضو باشند؛ در کانال مستقیم ادمین می‌شوند.
- هر ربات برای هر پیام یک ری‌اکشن می‌گذارد.
